# CC-GEO-1.5 世界生成与兼容报告

2026-10-29，Godot 4.5.1.stable.official.f62fdbde1。推荐260129、中型。旧1.4报告完整保存在 `evidence/v1_4/WORLD_REPORT.md`；其中旧路径、固定大陆和旧雕刻河道描述不适用于新局。

## 权威数据与新种子参数

世界由 `world_gen.gd` 组织；`seed_geography.gd` 生成有界随机球面地貌；`hydrology.gd` 从权威144×72格自然高程和降水推导汇流。6个地区ID语义稳定：0矿区、1农区、2高原、3草原、4海隔岛、5海岸；每个新种子的实际经纬、矿藏、气候和路径会变化。

`world.generation` 保存实际生成参数：大陆省区数量与位置/旋转/尺度，岛群、山脉，海岸域扭曲，全球旋转，温度与降水基准，主风向，气压、氧比例、海深和海拔尺度。`world.statistics` 从实际格网统计陆地比例、平均温度/降水/海深、最高海拔、实际陆地连通块数及生物群落格数。大陆按至少64格、岛按2–63格定义，不能把省区参数数组长度冒称实际大陆数。

地形采样为 `sample_geo(lat,lon,noise,version=VERSION)`。同一seed派生参数缓存，不逐像素重建随机列表。海岸包含多方向陆块、海湾半岛和岛链、多尺度球面噪声与域扭曲。海洋有沿岸大陆架到深海的连续负高程，不把保护开局用的局部陆地锚点变成全海洋浅水下限。正高程以4300米为单位；实际山脉高度和方向按seed变化。

气温受纬度、实际海拔、气候基准与气压温度修正影响，雨量受基准、噪声、山脉与风向影响；区域温度/水源/肥力进入农业和开发规则。氧比例限制在宜居区间并保存展示，未模拟人体生理。森林、草原、荒漠、苔原、高山等分类读取实际温度/降水/海拔；这不是全流体大气或板块演化模拟。

## 地形生成水系

不再先画一条固定河，再反向强制挖出河谷。水系沿实际格网8邻域严格下降，按降水和纬度修正汇流，保留主要干流/支流、汇合关系、海口和内流湖。青溪河谷候选在原位置6格半径内移向同一主大陆的真实汇水格，水源/肥力按气候与汇流增益计算。

`world.rivers` 是实际经纬路径；`river_metadata` 保存cell_path、沿线水面高度、末端类型与downstream_index；`hydrology` 保存主要河湖/海口统计；`grid` 保留汇水量和河湖标志。主要水系展示预算并不等于所有格网流水数。具体算法、测试和局部表现接口见 `HYDROLOGY_REPORT.md`。

## 全球、平铺和地区共源

球面与平铺使用同一世界；地区使用候选的 `canonical_lat/canonical_lon` 和真实球面变换。公开 `project_coordinate(lat,lon,world)`、`unproject_coordinate(...)` 和 `local_geo(world,region_id,x,z,noise)`，避免局部视图在世界整体旋转后仍读取另一块地理。河道由真实水系投影到地区；地区开发台地属于有限工程平整，不能把海洋当作可建陆地。

`route` 保留144×72格索引和四邻域陆路Dijkstra。普通路线避高脊，跨山路线承受更高工程造价和不同耗时。新260129中型实测0→1普通 **1124 km / 9天 / 1570**，跨山 **635 km / 3天 / 1638**。岛4没有陆路，禁止作为无后续可达据点的首府。

## 旧档兼容

`CC-GEO-1.4` 保留完整原采样函数；加载旧档直接使用档内世界与旧版本采样，不生成1.5替换旧大陆。网格尺寸、候选ID和原索引不变。`coast_review.gd` 实际读取 `evidence/v1_4/acceptance_midgame.json`，检查旧10368格所有高度/温度/降水和陆海/河湖标志，最大浮点误差为 **0.0**；正常旧UI第50日档在损坏档回归中也读取成功。

## 保留范围

主大陆仍保留受保护的经济发展核心与6个功能候选，这是开局可达性约束；大陆省区虽随机，仍是有界程序造型，不是自由地质年代演化。地理格144×72用于宏观物流和水系，显示纹理可以更细；不能把纹理分辨率当作等精度水文。地区是轻量工业沙盘，尚未达到商业级写实近景。地图节点不按居民人数创建，但大人口完整经济压力测试依然NOT_RUN。
