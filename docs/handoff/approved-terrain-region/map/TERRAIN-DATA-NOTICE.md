Retain the following source credits with the game and include a readable copy in release distributions. Each sampled dataset retains its source terms.

Planet layout, drainage, snow and the regional arrangement of the samples are generated from game data. The submitted review images show the resulting game renders. The land relief is a normalized local-detail derivative of tiles, for which the source mosaic does not expose per-pixel provider identification. The links above document the providers identified for the original sampled locations.
