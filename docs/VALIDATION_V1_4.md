## 实现的可玩范围

三种开局、三类有限矿床、六类实物、本地仓库、自动贸易及港口吞吐、公共设施建设/停工、农业、加工、教学研究与六项技术、汇总人口迁入/出生/成长、真实两地运输、一种自主运营的民营服务企业、三个有实际效果的事件、合同成功/失败/成功后沙盒和公司分成均接通。公共、居民、企业账户分别记账；内部转移带付款方与收款方，对外流量单列。

河谷与矿区的分工会发生实际货物流动。推荐种子的普通道路 913 km / 8 天 / 1348，跨山道路 712 km / 3 天 / 1763。装载扣起点库存，到货再入终点，运力和费用参与结算；岛屿不可陆路抵达。首次远征有一次性携带物资与旅行时间，后续运输需常设线路。

民营生活服务社由外部投资 900 起步，自动购买建设投入、雇工、付工资和维护费、支付本地租金、向居民售维修/洗衣/通讯服务、按正利润缴本地税。玩家设置行业/地区许可、税率与供应底线，公共关键产业仍直接管理。它不是完整竞价市场，也不是逐居民服务模拟。

## 画面、美术和性能

实际查看参考图、统一色板、三张已接入引擎的半身肖像、14个原生SVG图标、可分发中文字体及制作来源见 ASSETS.md。中文字重已从过细的默认变量字体改为静态500字重。行星是真3D球体，有云层、大气、昼夜光照和随聚落出现的灯光；地区是带坡地、水系、矿点、农田、道路和模块建筑的轻量3D沙盘。没有用烘焙界面图替代按钮。

`evidence/screenshots_release/` 来自最终 Windows 程序的显式 `--qa-capture=...` 开发入口：三个目标分辨率各7个页面，并各补16/20档字号的设置页和主界面，共33张。普通双击不运行此工具。实际逐张观察范围与发现见 `VISUAL_RELEASE_QA.md`；早期观察记录 `VISUAL_QA.md` 保留。图像生成和文件存在不自动算视觉通过。

硬件实查：Intel Core i9-14900HX、NVIDIA RTX4070 Laptop GPU，约31.6 GiB内存，Windows/ROG Strix G16 G614JIR。旧9C08DF构建每档暖机后抽120帧暂停行星场景，60fps上限：720p 59.10fps、1080p 57.89fps、1440p 56.91fps，P95均16.67ms；最终构建对应精确数据保存在 `screenshots_release/capture_report.json`。成功续玩会话平均59.79fps，P95 16.67ms。样本包含菜单/暂停或较短活动片段，**不是长时间负载稳定性、所有硬件或百万人口完整经济性能结论**。

## 保留的未完成项与限制

- **PARTIAL：20–40分钟目标节奏。** 正常自动路径第35–38日即履约，按1×每5秒一天约3分钟纯模拟等待；真正新手还需选址/阅读/操作，但没有用户样本验证到20–40分钟。不能用开发、截图、暂停或等待工具的总时长凑体验时长。后两个事件在第85/135日，多在履约后沙盒出现。
- **PARTIAL：写实地表精细度。** UI/肖像一致性已经建立，地表目前是低多边形工业沙盘；建筑的材质层次、近景细节和比例仍低于成熟商业美术。主要页面无占位图片，不能把风格统一升级为商业级写实完成。
- **PARTIAL：全部路径的人工覆盖。** 三种优势完整成功路径是自动act测试；实际UI覆盖资本路径和中期续玩，不能声称三条都从头人工通关。所有随机种子未穷举。
- **NOT_RUN：百万/千万/亿级完整经济压力测试。** 人口使用汇总数据，不逐人创建节点；这只是架构条件，尚未完成上述规模的完整长期经济验证。
- 固定大陆骨架与有限候选点，地理噪声/矿藏/气候受种子影响；不等于任意形态的全程序行星生成。仅陆运、两据点、24设施/地区，无海运、第三据点或全市场竞价。研究进行中可改投入，项目完成后再选下一项。
- 720p远景三维标签偏小、合同某些数字/单位换行生硬。详细视觉检查报告保留这些非阻断项。没有音效/音乐；本轮不把音频当已交付资产。

下一轮最值得投入的三件事：①围绕农业/物流/加工/科研重排合同阶段与事件，做独立新玩家计时试玩；②精修地表和建筑材质、相机及信息密度；③扩大种子覆盖与长期人口/供应链压力测试，继续增强异常存档回归。
