# 殖民契约 1.11.1 预览版（夜里的城市）

这是 1.11.0「承包人」之后的预览版，请朋友先看、提意见用。这一版只改了一件事：照灯光原画「沿海与内陆的灯光形态」做的城市夜景。规则和 1.11.0 完全一样，存档通用。

## 怎么运行

1. 把压缩包整个解压到一个文件夹里，`ColonyCharter.exe` 和 `ColonyCharter.pck` 要放在一起。
2. 双击 `ColonyCharter.exe`。需要 64 位 Windows 10 或 11，显卡支持 OpenGL 3.3。
3. 游戏没有数字签名，Windows 可能提示「已保护你的电脑」：点「更多信息」，再点「仍要运行」。

## 存档

- 1.11 的存档放在 `%APPDATA%\ColonyCharter\v111`，和 1.11.0 共用。
- 电脑上如果有 1.10、1.9、1.8 或 1.7 的存档，菜单上的「继续」会读取它们，按 1.11 的规则接着玩；原来的存档文件不会被改动。

## 这一版有什么不一样

详见 `CHANGELOG.md` 的「1.11.1」：

- **城市的形状。** 在球面上从默认距离往外看，每座城镇在夜里是一片城市灯光：亮着的街道网，中间一个白热的中心，越往外越稀，边缘参差。着陆点只有几点火光；首批住区、小镇、区域中心、星球首府一级比一级大，比例和原画一样，两级之间随人口慢慢长大。
- **沿海和内陆。** 沿海的城镇被海岸线切开，中心靠水，往内陆铺开；内陆的城镇向四周铺开。你修的路是从城里伸出去的亮线。
- **远处的设施和道路。** 离城镇远的矿场、码头、海底采矿平台和气象站各是一个小光点；修好的路是一条淡淡的光线。
- **拉近、拉远。** 镜头拉近时，城市的形状渐渐换成逐块建筑的灯光，两者不会叠在一起变亮。
- **夜景回放。** 结局和生涯页的夜景回放也用这些形状。
- **1.11.0 的内容**（合同文件、六种合同、年度船与报告、附件七和三种结局、天气、新闻、合并后的科技）都在，没有改动。

## 已知情况

- 这一版只在云端（Linux、软件渲染）测过，Windows 上的 EXE 还没有在真实电脑上打开过，也还没有在真实显卡上量过帧率。城市的形状由球面的着色器逐像素画出；如果夜里转动地球时变卡，请告诉我们你的显卡型号，可以在设置的「地图画面」里关掉云层或行星自转试试。
- 镜头距离 7.6 以内是逐块建筑的灯光，9.4 以外是城市的形状，中间渐变。形状比逐块灯光暗一些：在同一片地面上，大约是后者的六成。
- 平铺地图上仍然是逐块的灯光。
- 科技树定为合并后的 85 项（和 1.11.0 一样）。

## 请告诉我们

可以参考 `PLAYTEST.md` 的试玩清单。这一版最想知道的是：

1. 默认距离下，你的首府看起来像不像一座城市，和原画像不像；哪一级最不像。
2. 沿海城镇被海岸切开、往内陆铺开的样子，看起来自然吗。
3. 拉近、拉远时，城市形状和逐块灯光的交替顺不顺；有没有一下变暗或闪一下。
4. 帧率：夜里转动地球时卡不卡，你的显卡型号。
5. 崩溃或显示错误：截图（F12）和当时的存档。
