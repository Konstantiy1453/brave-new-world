# 殖民契约 1.11 预览版（开局的决定）

这是开发中的 1.11 预览版，请朋友先玩、提意见用。这一版想做到：开局的几个决定有分量；两次决定之间殖民地自己运转；你看得懂第一个据点能卖什么、一项投资要花多少、等下去能不能推进合同。正式版发布前还会继续调整。

## 怎么运行

1. 把压缩包整个解压到一个文件夹里，`ColonyCharter.exe` 和 `ColonyCharter.pck` 要放在一起。
2. 双击 `ColonyCharter.exe`。需要 64 位 Windows 10 或 11，显卡支持 OpenGL 3.3。
3. 游戏没有数字签名，Windows 可能提示「已保护你的电脑」：点「更多信息」，再点「仍要运行」。

## 存档

- 1.11 的存档放在 `%APPDATA%\ColonyCharter\v111`。
- 电脑上如果有 1.10、1.9、1.8 或 1.7 的存档，菜单上的「继续」会读取它们，按 1.11 的规则接着玩；原来的存档文件不会被改动。

## 这一版有什么不一样

详见 `CHANGELOG.md` 的「1.11.0」：

- **一张地点卡。** 地图上点任何一块陆地，就是这一点的地点卡：海拔和地势、建设费用、淡水、农田和一座农场的估计产量、海岸和渔场、各类地块、每种矿产的估计储量和范围。推荐地点只是可以隐藏的标记，点它打开的是同一张卡。
- **在这里先卖什么。** 卡上直接写出：矿产信号强的地方怎么出口矿石，肥沃的谷地怎么接粮食供应合同，好渔场怎么接渔获交付合同；要建什么、花多少、第一批货哪天、多少，多久能完成本阶段的出口目标。
- **第一阶段就能建第二个据点。** 付得起远征费用就能去，不必先完成 ¥40,000 出口目标。据点数量按合同阶段：2、3、5 处，之后不限。
- **供货合同。** 只收本地种出或捕到的货，居民的口粮不卖；交齐续签加量。货款算出口，计入合同目标，和卖给本地居民的收入分开写。
- **库存与生产。** 每个据点每种物资可以设「本地保留」和「减产线」；保留的部分不出口、不外调。库存满的设施保留职工、自动减班半薪。
- **下单之前的四个回答。** 现在付多少、哪支工程队什么时候开工、什么时候投产、在这里大概能多挣多少（一个范围，回本天数从下单日和投产日分别算）。没开工的工程可以撤回，钱和物资原样退回。
- **合同页和「⏩ 下一个决定」。** 每个目标写明照现在的安排能不能完成、什么时候、卡在哪里、可以做什么；「去处理」直接打开能做这件事的据点。顶栏的「⏩ 下一个决定」让殖民地照常运转，停在你选的时刻，或者在你可能错过一个选择之前。
- **事件。** 开局安静得多：第 75 天以后才有通讯，第一阶段很少打断你；越往后越多，也会有牵涉几个据点的决定。

## 已知情况

- 这一版在云端测过：游戏包（PCK）用 Linux 版引擎、EXE 用 Wine 9.0（软件渲染）跑了同一套界面检查。还没有在真实的 Windows 电脑和显卡上打开过。
- 后期矿场回本比 1.9 定的目标快（轻型矿场约 23–42 天，目标 70–150 天）：据点现在建在星球真实的矿脉上，品位更高。这一项还没有调。
- 机器人模拟中，第二阶段到第三阶段比 1.10 慢一些；详见交接文档。
- 民营经营场地暂时借用商业街区的模型；中型、大型货运码头和几种运输工具还没有自己的模型。

## 请告诉我们

可以参考 `PLAYTEST.md` 的试玩清单。这一版最想知道的是：

1. 地点卡上的「在这里先卖什么」有没有帮你决定首府放哪里；第一批货的日期和数量跟实际差多少。
2. 第一阶段你什么时候派出第二支远征队，派到哪里，为什么。
3. 下单前的四个回答哪一个最有用，哪一个看不懂或者不准。
4. 「⏩ 下一个决定」停下来的时机对不对：有没有停得太勤，或者该停没停。
5. 库存的「本地保留」和「减产线」用起来清楚吗。
6. 最困惑的三个时刻：游戏内日期、你想做什么、实际发生了什么。崩溃或显示错误请附截图（F12）和当时的存档。
