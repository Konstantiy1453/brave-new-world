# 殖民契约 1.12.0（新的地形与定居点）

这一版换了两样东西：新远征的地形（CC-GEO-2.3，山地和高原有积雪），以及照定稿第 06、07 版重做的定居点区域图。规则和 1.11 相同，存档通用。

## 怎么运行

1. 把压缩包整个解压到一个文件夹里，`ColonyCharter.exe` 和 `ColonyCharter.pck` 要放在一起。
2. 双击 `ColonyCharter.exe`。需要 64 位 Windows 10 或 11，显卡支持 OpenGL 3.3。
3. 游戏没有数字签名，Windows 可能提示「已保护你的电脑」：点「更多信息」，再点「仍要运行」。

## 存档

- 存档和 1.11 共用 `%APPDATA%\ColonyCharter\v111`，存档格式没有变。
- 旧存档保持原来的地形和原来的定居点位置继续玩；只有新远征用新地形。
- 电脑上如果有 1.10、1.9、1.8 或 1.7 的存档，菜单上的「继续」会读取它们；原来的存档文件不会被改动。

## 这一版有什么不一样

详见 `CHANGELOG.md` 的「1.12.0」：

- **新地形。** 新远征的大陆、山地、高原和水系由新的地形生成器生成；球面和卫星地图上的山地、高原有积雪，雪线随海拔、气温、湿度和坡向变化。
- **定居点按真实尺寸。** 建筑之间留出约 60 米空地，主路 8.6 米宽，支路 6.2 米，工业路 7.0 米；街道随地形轻轻弯曲。
- **街道跟着你的建筑。** 一排建筑连着的地方才有支路，离城远的矿场单独修路接到最近的路上。
- **地面、植物和岩石。** 风化壤土和稀疏草皮、路边压实的土和碎石、树、灌木、细草和风化巨石，都跟着落脚点自己的气候。
- **水。** 只有真正的海岸、河流和湖泊处才有水。
- **傍晚的光线和天空**照定稿调整。

## 已知情况

- 这一版在云端（Linux、软件渲染）测试过：全部测试、打包后的 PCK 用 Linux 引擎走过新远征、选落脚点、建造、存档和读档。Windows 上的 EXE 还没有在真实电脑上打开过，帧率也只在软件渲染下量过。
- 区域图里的树、草和岩石数量比以前多得多。如果进入区域图时卡，或者转动镜头时掉帧，请告诉我们显卡型号；可以在设置里换回默认画质（GL Compatibility）。
- 卫星地图的积雪和球面一致；地图缩到最近时，积雪的边缘会有像素感。

## 请告诉我们

可以参考 `PLAYTEST.md` 的试玩清单。这一版最想知道的是：

1. 新远征的星球看起来怎么样；雪山、高原像不像。
2. 定居点的大小、间距和街道看起来自然吗；建筑多了以后呢。
3. 地面、树和岩石，白天和傍晚看起来怎么样。
4. 帧率：进入区域图要多久，转动镜头卡不卡，你的显卡型号。
5. 崩溃或显示错误：截图（F12）和当时的存档。
