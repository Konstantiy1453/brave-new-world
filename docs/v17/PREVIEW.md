# 殖民契约 1.9 预览版

这是开发中的 1.9 预览版，请朋友先玩、提意见用。正式版发布前还会继续调整。

## 怎么运行

1. 把压缩包整个解压到一个文件夹里，`ColonyCharter.exe` 和 `ColonyCharter.pck` 要放在一起。
2. 双击 `ColonyCharter.exe`。需要 64 位 Windows 10 或 11，显卡支持 OpenGL 3.3。
3. 游戏没有数字签名，Windows 可能提示「已保护你的电脑」：点「更多信息」，再点「仍要运行」。

## 存档

- 1.9 的存档放在 `%APPDATA%\ColonyCharter\v19`。
- 电脑上如果有 1.8 或 1.7 的存档，菜单上的「继续」会读取它们，按 1.9 的规则接着玩；原来的存档文件不会被改动。

## 这一版有什么不一样

详见 `CHANGELOG.md` 的「1.9.0」：

- 星球会自转，有昼夜，夜里城镇和公路亮灯；云层随风带移动，海上有热带风暴。
- 建筑、施工现场、街上的车辆换成了近未来殖民地风格的模型。
- 新的短程穿梭机：一开局就能建，很贵、运得很少，但很快。
- 后期有五项新的巨型工程；钱的平衡调整过，中后期的钱更有去处。
- 地区工程和科研教育页面重新设计：建设分目录、设施、需求与产出三栏，科研课题卡的状态和效果更清楚。
- 按试玩意见修改（11 月 12 日）：地区场景更大、建筑切进山坡、车辆不穿建筑；城市夜景像卫星照片，随据点长大；顶栏显示每天的变化，货物按吨显示，「人口」改为「劳动力」，每三个月自动存档；「沿海航线」改为两端各一座小型货运码头，码头和公路都能升级；三项只能由事件获得的赠予科技；地面勘察可以做三次，一次比一次准。

## 已知情况

- 这个版本做过自动测试，但还没有在 Windows 电脑上完整检查过帧率。觉得卡时，可以在设置的「地图画面」里关掉云层或行星自转。
- 主菜单背后的星球刚出现时比较粗糙，几秒后会变清晰。
- 民营经营场地暂时借用商业街区的模型。
- 中型、大型货运码头，高速货轮、大型散货船和红球卡车还没有自己的模型：暂时把现有的码头和货船放大、把卡车漆成红色。

## 请告诉我们

可以参考 `PLAYTEST.md` 的试玩清单。最有用的是：

1. 最困惑的三个时刻：游戏内日期、你想做什么、实际发生了什么。
2. 最有意思和最无聊的部分。
3. 一局大约玩了多久，主要用哪一档速度。
4. 崩溃或显示错误：截图（F12）和当时的存档。
