# 殖民契约 1.10 预览版（海湾）

这是开发中的 1.10 预览版，请朋友先玩、提意见用。这一版先做好一个能玩的海湾：一支稀缺的工程队、内陆矿床和近海线索、第一批运出的货物，以及按真实建筑画出的夜景。正式版发布前还会继续调整。

## 怎么运行

1. 把压缩包整个解压到一个文件夹里，`ColonyCharter.exe` 和 `ColonyCharter.pck` 要放在一起。
2. 双击 `ColonyCharter.exe`。需要 64 位 Windows 10 或 11，显卡支持 OpenGL 3.3。
3. 游戏没有数字签名，Windows 可能提示「已保护你的电脑」：点「更多信息」，再点「仍要运行」。

## 存档

- 1.10 的存档放在 `%APPDATA%\ColonyCharter\v110`。
- 电脑上如果有 1.9、1.8 或 1.7 的存档，菜单上的「继续」会读取它们，按 1.10 的规则接着玩；原来的存档文件不会被改动。读档时每项在建工程会配一支工程队，不会卡住。

## 这一版有什么不一样

详见 `CHANGELOG.md` 的「1.10.0」：

- **工程队。** 建筑要有工程队施工才会推进，登陆时只有一支。它先修能解决缺水、缺电、缺粮的工程，再建你标了「先建」的，其余按下单顺序。左侧在建栏写出每项工程预计哪天开工、哪天完工；建设页上方可以培训、招募工程队，或把工程队派往别的据点。
- **第一个决定。** 工程队先修通往内陆铁矿的矿区道路（出口来得早），还是先建小型码头（粮食走海运便宜，渔船每天带回鱼，之后还能派测量船查明近海信号）？
- **第一次。** 第一车矿石运出、第一艘船靠上新码头时，会弹出卡片，点它去地区里看。
- **夜景。** 灯按真实建筑的位置亮：住区按入住的人亮窗，码头是冷色工作灯，夜里有船驶向泊位；近海信号是海上的金色圆环。交通网络图可以关掉。
- **按试玩意见修改。** 科研页、委托研究、农场预测、教程、暂停后的时间、事件的据点与调查回报、人口页的增长限制，都按上次的意见改过。

## 已知情况

- 这一版只在云端（Linux、软件渲染）测过，还没有在 Windows 电脑和真实显卡上检查过帧率和画面。觉得卡时，可以在设置的「地图画面」里关掉云层或行星自转，或换回标准画质。
- 球面默认距离下，你的海湾在夜里还只是几团小小的暖光和冷光，不像参考图那样一眼认出。请告诉我们在你的显卡上看起来怎样。
- 工程队的数量和价格是试玩用的初值：培训 ¥900、15 天，招募 ¥1,500、30 天。机器人模拟中，到第六年会有 12—24 支工程队。如果你觉得工程队太容易、太难凑够，请告诉我们。
- 机器人模拟显示，冲刺型和科研优先的打法在第五阶段更容易超期：工程队让后期的大工程慢了一些。
- 小型码头在自带农田的地点省不了多少钱，这时先修矿区道路更稳。
- 民营经营场地暂时借用商业街区的模型。中型、大型货运码头，高速货轮、大型散货船和红球卡车还没有自己的模型：暂时把现有的码头和货船放大、把卡车漆成红色。

## 请告诉我们

可以参考 `PLAYTEST.md` 的试玩清单。这一版最想知道的是：

1. 开局你让工程队先做什么，为什么；两种开局玩起来有没有不一样。
2. 工程队够不够用：哪一刻在等工程队，「先建」和左侧的日期有没有帮上忙。
3. 夜里从球面、平铺地图和地区里，能不能认出你的海湾；码头和船的灯看不看得到。
4. 教程里工程队那几步讲清楚了没有。
5. 最困惑的三个时刻：游戏内日期、你想做什么、实际发生了什么。
6. 崩溃或显示错误：截图（F12）和当时的存档。
