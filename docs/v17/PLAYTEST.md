# 殖民契约 1.8.0 试玩清单

一局现在很长：用 6× 跑完一局要半小时以上。可以分几次玩，存档会留着。目的是找出自动测试看不到的问题：看不懂、不好玩、不公平。玩之前不用读别的文档。

**人工试玩状态：NOT_RUN。** 下面的问题需要你亲自玩过才有答案。

## 准备

1. 解压 `delivery\v17\ColonyCharter-1.8.0-Windows-x64.zip`，双击 `ColonyCharter.exe`。
2. 主菜单保持「新手引导：开」，点「新建殖民远征」。
3. 手边开一个记事本，遇到卡住、看不懂或觉得不对的地方，记下游戏内日期和你当时想做什么。

## 第一部分：新手引导（15–20 分钟）

跟着左下角的引导走，不要跳过。

- [ ] 每一步都知道要做什么、为什么要做吗？哪一步要读两遍？
- [ ] 高亮框指的东西一眼能找到吗？有没有被挡住、跑出屏幕？
- [ ] 建筑要等二十来天：等的时候知道该干什么吗？会想按 3× 或 6× 吗？
- [ ] 研究那一步：「挑一张课题，派研究团队」看得懂吗？
- [ ] 第一支远征队：居住据点和边疆据点的区别看得懂吗？
- [ ] 路要修几个月：等路的时候据点撑得住吗？知道它什么时候修好吗？

## 第二部分：你提的那些改动（20–30 分钟）

- [ ] **顶部资源表**：总量和每月变化，一眼能看懂吗？电和水显示「供给 / 盈余」，你能接受吗，还是想看别的？
- [ ] **不信任表**：涨跌看得清吗？三道门槛的位置有用吗？涨得够慢了吗？
- [ ] **设施栏**：在建工程的日期和进度条够用吗？它挡地图吗？收起和展开顺手吗？
- [ ] **科研**：四个方向、每个方向几张牌，比之前的树好玩吗？想要的课题老不出来时，「重新调研」的价钱合理吗？
- [ ] **两种据点**：你有理由两种都建吗？建筑分到两边后，有没有想建却建不了、又不明白为什么的？
- [ ] **距离**：在 0.6 和 1.3 地球半径的星球上各开一局，感觉得出大小的差别吗？
- [ ] **海岛和航线**：试着从海岛开局，或者开一条航线。规则看得懂吗？
- [ ] **事件**：文字有代入感吗？连续开两局，感觉事件不一样吗？暂停的频率合适吗？
- [ ] **污染**：前几年是不是几乎感觉不到？后期它变严重时，你有没有提前的预感？

## 第三部分：长线（用 6× 跑，或读自己的存档）

- [ ] 六到八年的总督资格：太长、太短，还是差不多？哪一段最无聊？哪一段最紧张？
- [ ] 中后期钱花得出去吗？有没有哪段时间钱多得没处用？
- [ ] 最后一个阶段的首府人口和议会大厦，你知道要提前准备吗？土地不够的时候知道怎么办吗？
- [ ] 矿挖完时有没有预警？你知道该怎么办吗？
- [ ] 公司发来警告时，你知道原因和解决办法吗？
- [ ] 存档、退出、重新打开、继续：菜单上显示的星球、日期和资金对吗？

## 顺便看看

- 1.7 的存档：菜单上的「继续」或设置页能读出来吗？读完后世界还对吗？合同变长以后还玩得下去吗？
- 换不同分辨率和文字大小（保存与设置页）：有没有文字被截断或按钮够不着？
- 打开地区时有感觉到卡顿吗？区域地图变大了，城市放得下吗，镜头够用吗？
