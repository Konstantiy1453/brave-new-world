# 殖民契约 1.11 试玩清单：承包人

给朋友的前 30 分钟试玩脚本。目的是找出自动测试看不到的问题：看不懂、不好玩、不公平。玩之前不用读别的文档，也不用玩完一局。

**人工试玩状态：NOT_RUN。** 下面的问题需要真人玩过才有答案。

## 准备（2 分钟）

1. 解压 `ColonyCharter-1.11.0-…-Windows-x64.zip`（整个文件夹），双击 `ColonyCharter.exe`。
2. 手边开一个记事本。遇到卡住、看不懂或觉得不对的地方，记下游戏内日期（右上角）和你当时想做什么。
3. 旁观的人不要提示。试玩的人想到什么就说出来（边玩边说）。

## 第一段：签合同（5 分钟）

主菜单点「新建殖民远征」，先不要开新手引导。

- [ ] 六种合同卡片（标准承包、工程承包、科研托管、移民安置、矿权抵押、群岛开发）：只看卡片，你能说出每一种「给你什么、要你付出什么」吗？你选了哪一种，为什么？
- [ ] 开局后打开左侧「殖民合同」：一条一条的条款读得下去吗？哪一条让你觉得「这公司不好惹」？
- [ ] 公司的来信（发件部门、抄送、附言）：读起来像一家真公司吗？联络人的附言你会看吗？
- [ ] 顶栏的公司评级和民心：不点开，你知道它们各说的是什么吗？

## 第二段：落脚（10 分钟）

- [ ] 在球面上点一块地，看侧栏的地面报告，再点「在平铺地图上选址与勘探」比较几个地点。最后建首府。这个流程顺手吗？建好后自动回到球面，你注意到了吗？
- [ ] 前十个游戏日：你知道先盖什么吗？哪里让你停下来想了很久？
- [ ] 屏幕最底下那行新闻：你注意到了吗？读了几条？有没有哪条和你看到的情况对不上？

## 第三段：年度船和天气（10 分钟，用 3× 或 6×）

- [ ] 顶栏写着「公司船 N 日」。船来时的年度报告：如实、报达标、报超额，你怎么选？知道多报会留下账面差额吗？
- [ ] 第二年的指标比第一年高：你觉得公平吗？
- [ ] 有气象预警时（地图上的红圈、底部新闻）：你看见了吗？会花钱做防灾准备吗？
- [ ] 灾害之后：你知道可以申请不可抗力吗？（合同第 8 条，或者天气页）
- [ ] 有没有一段时间你觉得「没事可做，只能等」？大约多长，在第几年？

## 第四段（可选）：长线

用 6× 或读朋友的存档，跑到第四阶段验收以后。

- [ ] 附件七启封时：里面写的东西让你意外吗？照办、周旋、公开，你选了哪个，为什么？
- [ ] 拿到总督资格后：效忠、买下殖民地、宣布自治，你想走哪一条？结算单读得懂吗？
- [ ] 结局后的夜景回放（约 20 秒）：看得出殖民地是怎么长起来的吗？

## 问试玩的人

1. 用一句话说说：你在这个游戏里是谁？公司是什么？
2. 最想再玩一次的是哪一段？最不想再玩的是哪一段？
3. 有没有哪个数字或按钮，你直到最后也不知道是什么意思？
4. 公司让你觉得紧张、好笑，还是没感觉？
5. 如果要删掉一样东西让游戏更简单，你删什么？

## 记录下来告诉我

试玩的人、选的合同、玩了多久（真实时间和游戏内日期）、卡住的地方（游戏内日期 + 想做什么），以及上面五个问题的回答。截图或存档（`%APPDATA%\ColonyCharter\v111`）也有帮助。
