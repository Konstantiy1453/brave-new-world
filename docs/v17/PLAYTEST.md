# 殖民契约 1.7 试玩清单

用时 30–45 分钟。目的是找出自动测试看不到的问题：看不懂、不好玩、不公平。玩之前不用读别的文档。

**人工试玩状态：NOT_RUN。** 下面的问题需要你亲自玩过才有答案。

## 准备

1. 解压 `delivery\v17\ColonyCharter-1.7.0-Windows-x64.zip`，双击 `ColonyCharter.exe`。
2. 主菜单保持「新手引导：开」，点「新建殖民远征」。
3. 手边开一个记事本，遇到卡住、看不懂或觉得不对的地方，记下游戏内日期和你当时想做什么。

## 第一部分：新手引导（10–15 分钟）

跟着左下角的引导走，不要跳过。

- [ ] 每一步都知道要做什么、为什么要做吗？哪一步要读两遍？
- [ ] 高亮框指的东西一眼能找到吗？有没有被挡住、跑出屏幕？
- [ ] 第一个红字问题（供水不足）出现时，你看懂了原因吗？「处理」按钮把你带到了对的地方吗？
- [ ] 比较两种公路时，知道该选哪条吗？
- [ ] 全程大约用了多少分钟？哪里觉得拖沓？

## 第二部分：自己玩到第二阶段（10–15 分钟）

引导结束后继续玩，也可以新开一局，选另一个开局方案和种子。

- [ ] 地点卡片的信息够你决定在哪里建据点吗？
- [ ] 建设目录里的回本天数和每日净额，会影响你的决定吗？
- [ ] 经营账本能看懂钱从哪来、到哪去吗？
- [ ] 研究值得投入吗？5 人和 10 人的差别看得出来吗？
- [ ] 事件暂停的频率合适吗？暂停时有东西可选吗？
- [ ] 有没有哪一刻完全不知道下一步该做什么？

## 第三部分：长线（10–15 分钟）

用「极快」跑到总督资格，或读一个自己的存档继续。

- [ ] 总督资格来得太早、太晚，还是差不多？
- [ ] 矿挖完时有没有预警？你知道该怎么办吗？
- [ ] 公司发来警告时，你知道原因和解决办法吗？
- [ ] 钱多了以后还有想花钱的地方吗？
- [ ] 存档、退出、重新打开、继续：菜单上显示的星球、日期和资金对吗？

## 顺便看看

- 有 1.6 存档的话：菜单上的「继续」或设置页的「读取 1.6 手动档」能读出来吗？读完后世界还对吗？
- 换不同分辨率和文字大小（保存与设置页）：有没有文字被截断或按钮够不着？
- 地图上的卡顿：打开地区、自动存档（每 10 天）时有感觉到停顿吗？

## 记录下来告诉我

1. 最困惑的三个时刻（日期、你想做什么、发生了什么）。
2. 最有意思和最无聊的部分。
3. 引导用了多久，你是否看完了全部 14 步。
4. 崩溃或显示错误：截图（F12）和当时的存档，存档在 `%APPDATA%\ColonyCharter\v17`。
