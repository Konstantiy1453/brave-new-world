## 非阻断记录

1. **P3：合同段落存在数字与单位分行。** 例如“至少 7 / 天”“连续 12 / 天”，以及“公共资金 ￥ / 5321”。内容未丢失、条件可理解，但以后宜将数字和单位置于同一短语，改善中文阅读节奏。三档同样可见，因此不是只在 720p 发生的溢出。
2. **P3：地区场景的初始生活舱和门架小字在默认远景尤其 720p 较小。** 右侧相应住房与路程信息仍清楚，建筑可以按形状分辨；场景文字应继续作为辅助标注，玩家可用已提供的镜头缩放近看。本轮静态截图没有再次操作镜头。
3. **表现限制：区域为低多边形工业沙盘。** 河流和丘陵明确，设施不是默认立方体；树石、地形及全球山脊着色尚未达到摄影写实质感。这里记录为当前美术完成度边界，不将其表述为照片级成品。
4. **历史已修复：原始日志字段暴露。** 首轮三张事件图可见 `day`、`text` 等序列化字段。最终三张事件图均已用中文日期和消息替代，缺陷在这三个最终样本中关闭。
