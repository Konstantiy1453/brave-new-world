# CC-GEO-1.5 水系生成与验证

2026-10-29。实现为 `game/world/hydrology.gd`，在种子决定的权威144×72球面高程网格及候选区域生成后执行。旧CC-GEO-1.4存档继续读取既有河流，不套用新水系。

## 规则与数据

每个陆地格检查八个相邻格，只选择比自身严格低的接收格，以坡降/球面距离择优；经度首尾相邻。按高程从高到低累积降水与纬度面积权重，形成有来源的汇水量。汇水量是归一化指标，不是立方米/秒流量。没有先画直线河流再用它决定大陆，也没有让水沿高程爬坡。

较大的集水路径成为地图上的主要河段。已有河段接收新的支流时，保存明确的下游河段索引和汇合格；自然低洼处形成内流湖，排入海洋的河道具有海洋终点。主要河段显示预算根据实际陆地格数与平均降水在10–36之间变化，完整汇水信息仍保留在所有陆地格中；因此显示的河段数不是世界所有细流的穷举。湖泊为0.25–0.75度半径的子网格内流湖，不能理解成整个2.5度网格都被湖水淹没。

农业候选在其原位置6格半径内、与矿区相同的陆块上选择较低的真实汇流格。肥力与供水由已有气候条件加上汇水收益获得，不把所有星球的河谷都写死成相同值。该迁移不增加物资，也不替代真实道路连接。

权威字段：

- `grid[].discharge/river/lake`：归一汇水量及地图水文标志。
- `world.rivers`：每条实际纬经坐标路径，点格式为 `[lat,lon]`。
- `world.river_metadata[]`：`cell_path`、归一水面 `heights`、`terminal`（ocean/lake/confluence）、`downstream_index`、流量指标、源与末端高程。
- `world.lakes`：中心实际纬经坐标、`radius_degrees`、归一`height`、米制`elevation`、汇水量及所在网格。
- `world.hydrology`：生成方法、主要河段/湖泊/河口数、显示预算、候选水道数与农业汇流格。

## 与场景的对应

球面与平铺地图绘制同一套 `world.rivers/lakes`。地区场景按同一河段裁剪，并使用 `river_metadata.heights` 插值水面。地图实现者已确认地区河道床面采用“插值水面减0.28本地单位”，在两岸平滑接回连续地形，建筑和道路也调用相同地表采样。这样不会把仅仅“原地形减一个常数”误当成足以保证水面连续。

本文件实际验证了网格坡向、河段元数据、重复生成与道路可达。连续地区水面、河床和画面质量的实测由地图渲染报告和最终截图验收承担，不用网格PASS代替实际画面检查。
