# 原创事件实现与证据（1.6）

实现文件为 `game/simulation/events_v2.gd` 和 `game/data/events_v2.json`。本次没有读取新的外部剧情脚本；只依据既有 `events_review.md` 中已说明的条件抽取、延迟后继、调查改变选项、持久后果等机制建议，文字、故事、数值及分支为本项目原创。

## 已实现规则

- 10 个条件短事件、3 条完整分支链。条件检查设施、人口、出口、据点数、合同阶段、此前结局；通过条件后才使用独立 Park–Miller 随机流按权重抽取。随机状态、实例序号、定义版本及已出现列表全部保存。
- 最早第 6 日进入水线链；之后候选抽取间隔为 6 日。每个定义每颗星球出现一次；负面短事件间隔至少 18 日，同一时刻最多 3 个未结案现场。尚有待决/延期卡时不继续抽新卡。此为候选节奏参数，不是充分人类试玩调平结论。
- 必须决定的节点 `pause_required=true`。只有明确选择“稍后处理”才解除该节点的强制暂停；同一节点不可重复延期。默认期限 6 日；暂停不推进日历。超时按节点配置执行默认选择，历史记录 `automatic=true`。
- 所有暂时效果从决定后次日起生效，区间 `[start, until)`；持续 N 日准确覆盖 N 次生产。手选与到期默认使用同一效果入口。文字和 UI 倍率、持续日数、维护费由实际配置生成。
- 资金经 `_transfer/_public_expense`；实物经 `_produce/_consume`。同一实例结案后不能再次执行选项。权利出售及资料销售为一次性非经营收入，订单到货为真实外部经营收入。
- 现场调查使用同一科研人员池，优先占用现有人口中的 3 人。项目分配随真实人员减少；撤回调查释放人员，再用科研界面重新分配。没有复制研究员。调查可以主动撤回，人员不足 45 日则封存，保存工作量。
- 目标不存在时主动操作原子拒绝，下一日记录取消；新泵站被替换/移除则记录工程目标失效。工程在 30 日内未投入运行则明确结案。事件没有绑定民营公司或陆路，因此不会假装提供公司更换/道路替换专属故事分支。

## 三条链的真实后果

| 链 | 实际等待条件 | 主要结局 |
|---|---|---|
| 第二条水位线 | 3 人调查；通过普通建设动作建净水泵站，须实际竣工并运行才能验收 | 配水协议：供水 ×1.10、矿业 ×0.90、农业 ×1.08；清渠/精测验收：供水 ×1.15、农业 ×1.10并产生维护费；含盐扩张：供水 ×1.20、农业 ×0.88；封存、工程失败、主动撤回等完整退出 |
| 送不到的旺季 | 加工厂真实制造部件；本地产出标记，进口件不能冒充；实际占用港口剩余吞吐，装船后三日到货 | 按实际抵达量与固定单价支付；中途可继续、付费延期、协商减量；准时交付可保留货站 ×1.05 的操作规范，或单次结案；逾期按已经抵达的数量结清，不发虚构全额奖励 |
| 岩层下的值班簿 | 三人实地整理值班簿，再选择保护、样本分析或出售独家后续调查权 | 查明勘探队主动撤离的完整小故事；公开记录可改善采矿 ×1.05；完成样本后可采用 ×1.12 筛分工艺或仅归档；出售取得一次性收入，8 日后大学简报交代结局，不能再领同一现场成果 |

订单在装船时消耗当地库存并记为已出口物资；`order.cargo` 保存尚待外部收货的航程回执，抵达时才产生货款。它不再属于可回调的本地库存，也不重复列入陆路库存审计。订单总账须满足 `dispatched = delivered + cargo`、`paid = delivered × price`。正常现货交易必须保护未交付订单需要的**本地产出**，不能仅保留等量进口件。

## 接口与存档

- `ensure(sim)`、`tick(sim)`、`act(sim,args) -> String`、`view(sim) -> Dictionary`、`validate(candidate) -> String`。
- `modifier(sim, region, kind)` 应用于真正的水量、农业、采矿、加工与货站能力；`reserved(...)` 保护已承诺的订单货物。
- UI 使用 `view.pending/active/history/effects`；选项含 `id/label/enabled/reason/cost/duration_days`，只读查询不抽签、不推进工作。历史/影响有中文 `title/text`。兼容 `state.event` 镜像只用于旧界面入口。
- 每个实例保存定义版本、绑定地区、当前节点、生命周期、选择历史、计划后继、调查/订单变量及结局；日结以 `last_tick` 防重复。记录有界，全部定义单次最多 13 个实例。
- 嵌套校验拒绝未知定义/节点、错误版本、非法类型、越界目标、重复实例、无来源影响、失衡订单、无调查预留的工作量。失败加载由模拟器保持原内存状态。此为结构/经营一致性验证，不是恶意存档防伪认证。
