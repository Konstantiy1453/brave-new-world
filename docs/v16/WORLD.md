# CC-GEO-1.6 地理、地区缓存与道路截止日

本轮范围为 F03、F04、F12，并在地图初始化时同步修复 F09 的地图选区残留。原项目保留，历史审查文件未改写。下面的运行结果均属于 2026-10-30 v1.6 源工程；图形检查为独立地图窗口自动导航，不是最终 EXE 或人工完整试玩。

## 实现与兼容

- `SeedGeo.normalize_seed(Variant)`：有符号 32 位整数原值保留。其余整数按模 2^32 解释为有符号整数；十进制字符串逐位取模，不经过浮点数或 int64 解析，因此支持 int64 边界以及更长的十进制输入。其他文本使用 Godot 字符串哈希，再规范化到相同范围。
- `WorldGen.generate(Variant)` 保存 `seed`（唯一有效种子）、`seed_input`、`seed_protocol=signed32-mod-v1` 和 `version=CC-GEO-1.6`。噪声、气候/旋转参数、候选点、资源、全局网格、地图图集与地区采样共用该有效种子。UI/模拟层需传入原始文本，并用有效种子初始化模拟随机流。
- `world_compatibility_error(world)` 支持 signed32 的 v1.4/v1.5 完整旧世界。超范围旧种子的全球图与经营网格本来就不一致，明确拒绝载入并说明恢复路径：保留原文件，使用 `versions/v1_5_before_v1_6_20261030_125059` 中旧构建继续，或以原种子新建独立生涯。该检查不修改旧世界、不生成替代地形；完整读档提交/内存回滚由模拟层集成验证。
- 图集缓存键升级为 `atlas-1536-r4-seed32`，避免沿用旧协议贴图。内存图集最多 2 个、磁盘派生图集最多 2 个、种子参数缓存最多 32 个。首次显示直接使用保存的 144×72 权威网格形成预览，随后原来的 1536×768 图集在线程中细化；最终分辨率保持原值。
- 地区地形仍为原 86×86 网格、相同三角形顺序、颜色和法线。每个唯一格点只采一次，共 7569 次，六顶点展开复用结果。海面仍保持原 0.5 间距采样。
- 每张地图保留最近使用的 3 个地区场景。地形节点、河流/湖泊上下文复用；建筑/施工/停用/基础住房/道路状态按签名更新。换世界或读档 `setup()` 清空地区缓存、取消未完成任务并重置地图选区为 0。
- 冷地区每两行让出一帧，`show_region()` 立即返回，提供 `region_busy`、`region_progress(busy, progress)`（进度 0—1）、`region_ready(id)`、`cancel_region_load()`。球面/平铺导航自动取消；任务令牌阻止旧任务写回新世界。取消是 `busy=false, progress=0`，完成是 `busy=false, progress=1`。
- `WorldGen.road_blocked(route, day)` 统一为包含截止日的 `blocked_until >= day`。地区路口文字、球面/平铺道路颜色读取此规则；模拟运输和合同连通性由模拟模块调用同一函数。

## 耗时与观察

硬件：Intel Core i9-14900HX；图形测试 NVIDIA GeForce RTX 4070 Laptop GPU。每项下列值是一轮固定操作的实测样本，不是分布或 P95。

| 操作 | 首次反馈/处理 | 稳定完成 |
|---|---:|---:|
| 无窗口：冷地区0 | 0.133 ms（调用返回） | 692.106 ms，92 次让帧 |
| 无窗口：同地区重复 | 0.124 ms | 0.124 ms，0次地形重建 |
| 无窗口：建筑已变更后返回 | 5.305 ms | 5.306 ms，0次地形重建 |
| 无窗口：另一地区后返回 | 0.262 ms | 0.263 ms，0次地形重建 |
| 无窗口：地区1/2/3冷加载 | 0.052—0.077 ms | 695.071—736.318 ms |
| 图形：地区0冷加载，同时精化图集 | 调用0.062 ms；首个呈现帧113.947 ms | 1750.326 ms |
| 图形：同地区重复 | 调用0.402 ms；呈现2.231 ms | 3.550 ms |
| 图形：球面后返回 | 调用0.211 ms；呈现16.129 ms | 32.681 ms |
| 图形：地区1冷加载 | 调用0.229 ms；呈现16.622 ms | 1562.449 ms |

图形首次冷加载的一次首帧为113.947 ms，未达到约100 ms的目标；首次GPU呈现包含在此样本中。后续冷地区反馈16.622 ms，已加载地区没有重建。冷加载观测到的最长帧为67.685 ms/56.569 ms，说明工作已分帧但并非每帧都小于16.7 ms。后台高精图集完成6231 ms，期间地区交互继续运行。

直接网格预览后，地图setup为无窗口92 ms、图形102 ms；此前本次初始实现仍重新采样384×192预览，setup约2.1秒。冻结v1.5例程构建同一地区地形为3363.422 ms；优化后完整地区为689 ms（此对照来自独立地形一致性运行，与前表不是同一次计时）。历史审查的5秒级数值保留原报告口径，不直接称作同环境P95对照。

已实际查看四张1280×720图：地形、建筑、河流和全球地理可见，球面/平铺对应同一世界。边界种子的平铺图存在相邻地区名称重叠；地区河流仍有原模型的明显切边/阶梯感。本轮未扩展美术重制。测试窗口不包含完整经营面板；最终EXE、OS真实点击、三档UI分辨率/缩放与人工试玩属于总交付验证，不能由此报告代替。

## 后续集成审查：暂停停用与球面返回

实际地图回归发现并修复两条状态刷新遗漏：在地区中改变选区后返回球面，球面标记颜色现会刷新到当前选区；建筑签名和绘制同时读取 `enabled`，因此暂停时停用建筑也立即显示停工色，不依赖下一次日结更新 `active`。`world_v16_ui_sync.gd` 的三个断言先红后绿，分别检查真实球面标记材质、建筑根节点刷新和停用材质。见 `world_ui_sync_red.json`、`world_ui_sync_green.json/.log`；最终运行退出码0，failures为空。该窄修复不改变地形数组。

`world_v16_legacy_load.gd` 进一步通过实际 `Sim.load_game` 验证旧档边界：完整 v1.5 世界经迁移后 `var_to_bytes(world)` 逐字节保留；重新生成有效外层校验的超范围种子坏档被拒绝，原内存状态和存档文件均保留。该运行退出码0，见 `world_legacy_load.json/.log`，补足前文纯兼容检查到真实载入提交路径之间的验证。
