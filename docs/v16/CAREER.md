# 1.6 连续生涯与代管结算

唯一活动星球使用完整逐日模拟；旧星保留完整压缩快照，后台只跑汇总账户。配置 `game/data/career.json`，实现 `game/simulation/career.gd`。

预测取最近30日经营收入和成本，并按现有实际启用产能限幅。去除经营支出中已经发生的公司分成/援助附加费，再作为独立义务结算，防止重复征收；闲置设施仍有维护成本底线。一次性融资和奖励不在经营样本中。各已建矿场的有限矿床独立计量，未建矿场资源不补贴现有矿业。农产/加工/食品订单提供有上限的非矿业基准。

每日先收真实模型收入、支付维护/运营与已知欠款、履行救助本金和附加分成，再计算公司合同所得。月末先留足30日经营准备金；本期正净额与可用现金二者取小，欠款未清则不分红。余款玩家60%、代管方40%，不另收管理费。转出额从旧星现金扣除，玩家份额记入生涯资金。玩家主动注资属于新星外来融资，不能完成新星连盈。

每个账期有唯一身份，重复tick、加载和重新打开界面都不产生第二次付款。经营和历史记录有界（90条月报），不会每月复制世界。代管只随游戏日历推进，没有现实时间离线收入。

移交在独立候选状态中完成：完整旧星快照+摘要、新星开局、全局日期、检查点一并验证并成功写盘后，才替换当前内存。失败路径保持原世界、余额和人口。重开恢复本星登陆时完整生涯，不保留失败尝试新赚取的钱，也不重复发放开局资本；改变难度时仅重新应用一次开局参数。

验证：21项基本生涯回归，19项日期/重开/矿床边界，7项独立税额/快照检查；另有全新正常动作第一星任命→移交→第二星36日→543.18分红→100注资→存读续算一致（金额以最终acceptance_flow.json为准）。全局359日开第二星、第360日结算、新合同仍有效，属于明确的日期边界夹具，不混称自然360日通关。

局限：旧星每日供需、物流、灾害和人口波动由稳定基准近似；救助物资保留交付回执，不继续逐库存运营。默认代管不会自动转型或无限开发新矿；矿业衰竭可能让分红归零和当地积累欠款，这不会挪用新星现金。玩家不能返回旧星操作，A留任模式未接入。
