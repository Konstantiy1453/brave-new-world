# 殖民契约 · COLONY CHARTER 1.6

Godot 4.5.1 原生 Windows x64 单机殖民经营 Demo。本轮依据 `docs/superpowers/plans/2026-10-30-next-demo-agent-instructions.md` 在现有工程迭代。当前使用 CC-GEO-1.6；旧版工程、构建与用户存档保留在 `versions/v1_5_before_v1_6_20261030_125059`。

## 启动与快速体验

双击 `build/v16/ColonyCharter.exe`，与同目录的 `ColonyCharter.pck` 一起保留。发行整包位于 `delivery/v16`，无需安装编辑器。新生涯推荐种子 **260129**、中型、资本储备、标准难度；另外提供 **20261029**、**42** 作为对照。种子可以是数字或文字。

左上角始终提供“存档”和“读档”；Ctrl+S 手动保存，F12 截取实际画面。打开管理面板会暂停，关闭后用空格或正常/快进继续。正常5秒一个游戏日、快进4倍，30日/月、360日/年。重要事件、公司审查、任命及接管会立即中断快进。

“保存与设置”内有四个1.6验收入口：危机整改、事件中段、总督移交前、第二星球分红后。它们全部来自自动执行正常游戏动作；不是新局默认状态，也不是人类试玩计时。主菜单直接提供事件中段。普通新局无需这些存档。

## 一次完整经营

1. 选择铁岬盆地建立首府，建设铁矿与铜矿，保留水电、货站和足够工人。观察本地库存与资金流水。
2. 允许生活服务社后，它用企业账户支付工资和经营成本，自动向居民收费并交税。小前哨需求可能不足；可支付重组投资复业或迁址。
3. 选择青溪河谷建立第二据点，比较绕山与跨山线路，建设农场。货物真实进入在途队列，抵达前不能消费；港口出口保护跨区补给及订单承诺。
4. 建研究所，实际分配科研人员；调查与技术研究共用团队。5人的基础速度为10人的60%，0人暂停保留研究量。有研究任务的实验所维护工优先于矿场，因此集中科研会暂时减少矿业劳力。
5. 用生产管理设置库存目标、批量启停公共设施。作物适配解锁食品出口加工坊，提供可再生食品订单收入；矿床储量有限。
6. 公共经营连续12日达标，并满足双据点连通、食品、住房、就业、产业与民营企业要求，取得总督资格。公司只对正经营结余收取合同分成。
7. “生涯代管”可查看预测并确认B代管、前往下一颗星球。旧星保留完整交接快照，后台按实际经营基准、矿床、债务和援助义务结算。先补当地周转，再支付公司、代管方和玩家；分红不保底，也不会从新星自动扣款。
8. 玩家分红进入生涯账户，主动注资到新星；它不计新星当地经营利润。第二星合同年龄从0日重新开始，全局日期和旧星账期连续。重开恢复整个登陆检查点，包括该次尝试的分红、注资、随机状态和旧星账期。

公司不信任由经济、社会、环境来源组成，依次经历关注、审查、介入和恢复。旧版欠款、断粮、超期不会绕过整改窗口直接判负。援助条款有明确抵达日、偿还金额、分成和结束时间，确认前可查看。持续违约仍会被接管。

10个原创短事件和3条分支链覆盖水线工程、真实工业订单与考古值班簿。必须决定的节点暂停；“稍后处理”才恢复截止计时。调查、建设和运输使用真实人员与产能，选择及后果可在通讯记录中查询。

## 存档、旧版与回退

新版正式用户目录为 `%APPDATA%/ColonyCharter/v16`，手动 `manual.json`、自动 `autosave.json`，原子替换并保留 `.bak`。自动存档每10模拟日；退出前建议手动保存。测试全部另设APPDATA目录，不写玩家档。

1.4/1.5合法旧档可读取并迁移，世界身份与地理保留。设置页可读取旧版手动档，原文件不覆盖。历史越界整数种子若各视图已有矛盾会明确拒绝，避免静默改造旧世界。旧档没有登陆检查点时仍可经营，但无法凭空重建其开局；取得资格后移交会创建新的完整检查点。

回退时启动上述 `versions` 中保留的旧EXE/PCK和旧存档。不要把1.6档交给1.5读取。新建远征是独立生涯，不自动继承其他生涯资产；原来的手动档在主动覆盖前保留。
