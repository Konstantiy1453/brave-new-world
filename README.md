# 殖民契约 · COLONY CHARTER 1.7

单机殖民经营游戏。你是公司的殖民外包专员：选址、开矿、养活大家，把几处据点连成一个能自负盈亏的社会，赢得总督资格，再去下一颗星球。离线、免费、无内购。

Godot 4.5.1，GL Compatibility，Windows x64。

## 开始

解压 `ColonyCharter-1.7.0-Windows-x64.zip`，把 `ColonyCharter.exe` 和 `ColonyCharter.pck` 放在同一个文件夹，双击 EXE。

第一次玩请保持主菜单的「新手引导：开」。引导用一颗专用星球，走完 14 步大约 15 分钟，可以随时结束，也可以在「保存与设置」里重新开始。

## 核心规则

- **合同分三阶段。** 立足（出口、食品、研究）、分工（第二据点、本地粮食、加工、人口、技术）、自立（人口、就业、住房、民营企业、非矿业收入）。每阶段有奖励和新据点许可。错过期限不会立刻结束游戏，但公司的不信任会上升。
- **公司的流程。** 不信任累积后依次是关注、审查、有条件介入、接管。公司关系页列出每一条原因和期限，解决原因就会回落。
- **三个账户。** 公共、居民、企业分开记账。建设和融资不算经营；工资和消费是账户间转账。
- **矿会挖完。** 地块有品位和储量，轨道数据只是估算，勘察后才准。出口越多价格越低，别只卖一种。
- **人是有原因地来和走。** 吸引力列出每一项原因。床位满了没人来，失业的人多了新移民也不来。工资影响吸引力，招募来得最快但越招越贵。
- **研究要集中。** 5 人的速度只有 10 人的 60%。分散团队会慢，而且受实验台限制。
- **路各有利弊。** 河谷公路便宜但绕远，工程公路直接但养护贵，还可能落石封路。封路时货物原地等待，不会丢。
- **总督之后。** 可以继续经营，或把星球交给代管，分红进入生涯资金，再选种子、大小、开局和难度去下一颗星球。

遇到问题先看右侧红字，旁边的「处理」按钮会带你去解决。「行动指南」有更短的说明。

## 存档

存档在 `%APPDATA%\ColonyCharter\v17`：手动档 `manual.save`、自动档 `autosave.save`（每 10 个游戏日）。写入失败不会破坏旧档，还有 `.bak` 备份。

1.6 和 1.5 的存档可以读：主菜单在没有新存档时会用「继续」读 1.6 档，或到「保存与设置」选择。原文件不会被改动，旧存档保留原来的世界。

## 回到 1.6

1.6 的程序在 `build\v16\`，发行包在 `delivery\`，代码在 git 标签 `v1.6.0`。1.6 的存档在 `%APPDATA%\ColonyCharter\v16`，1.7 不会改动它们。1.7 的存档 1.6 读不了。

## 已知限制

- **还没有真人试玩过。** 数值是用自动机器人调的，不代表真人的感受。试玩清单在 `docs/v17/PLAYTEST.md`。
- 机器人仍有一部分局在拿到总督之后因矿挖完而破产；真人可以调整，但后期经济可能比想象中紧。详见 `docs/v17/BALANCE.md`。
- 只支持 Windows x64。没有多人模式，也不模拟单个居民。
- 旧存档保留旧地图，没有新地图的河流和气候细节。

## 源码

工程在 `game/`，入口 `game/project.godot`。规则数值在 `game/data/v17/*.json`，模拟在 `game/simulation/`，界面在 `game/ui/`，地图在 `game/world/`。

```powershell
# 全部测试（每个套件独立进程）
powershell -ExecutionPolicy Bypass -File tools\run_tests.ps1
# 平衡测试（--quick 约 2 分钟，--full 约 10 分钟）
$env:APPDATA = 'D:\勇敢新世界\evidence\v17\userdata_tests'
& tools\godot-4.5.1\Godot_v4.5.1-stable_win64_console.exe --headless --path game --script res://tests/balance/run_balance.gd -- --quick --label=note
# 打包（在没有改过 APPDATA 的窗口运行）
powershell -ExecutionPolicy Bypass -File tools\build_v17.ps1
python tools\package_v17.py
```

设计说明、平衡结果和验证记录在 `docs/v17/`，更新内容在 `CHANGELOG.md`。
